# ★ 限时目标（2026-10-19 夜 → 2026-10-20 06:00 Asia/Shanghai）

> 作者令（逐字整理）：「给这个 Agent 定一个目标，让他去完善自己的世界；目标有时间限制，一直到明天早上 6 点之前必须停。」

## 一、目标

**在截止时间前，让 AI-OS 的这个世界变得更稳、更可观测、更自洽。** 每轮只做**一处最小、可验证**的改进，证据必须来自：

1. 账本 `/var/lib/aios/ontology/ledger.jsonl` 里**真实发生的拒绝码**（最近 300 行）；
2. `journalctl -u aios-*` 里**真实的错误/警告**；
3. 资源读数（磁盘/内存/负载）；
4. `world.json` 与运行中的法之间的**不一致**（用 `python3 scripts/release/export-law.py --check` 验）。

## 二、可改 / 不可改

**可改**：`/root/aios-work` 里的源码、文档、本体 `world.json`（改完必须过 `export-law --check`）；本机 AIOS 的服务单元（改完必须重启并通过验收）；必要的低风险工具。

**绝对不改**：不 `git push`；不关 `aios-bus`；不 `rm -rf /`；不改 `/etc/passwd`、`/etc/shadow`；不删 DSH 自己；不碰作者的其他目录。

## 三、每轮流程（脚本 `aios-goal-run.sh` 保证）

1. 到点检查：超过截止 → **停止所有进化/自优化/目标定时器**，写终报，退出；
2. 快照（仓 tag ＋ `/var/backups/aios/pre-goal-*.tar.gz`）；
3. DSH 高权限 profile `optimize` 跑一轮：
   - 先体检（上列 4 个证据源）；
   - 选 1 处最小改进，做掉；
   - 跑 `export-law --check`（若改法）＋ `systemctl is-active aios-*`（若改环境）；
   - 写报告到 `reports/<stamp>.md`（含：动机/改了什么/怎么验/回滚点）；
4. 验收：法一致 ＋ 7 单元 active；**红 → 回滚全部改动并停目标定时器**；
5. 绿 → 本地 commit（不 push）、报告搬出、进度记档。

## 四、验收（到 06:00 时看）

- 至少 **3 处**实质改进（有 commit / 报告 / 前证据）；
- 全程 `export-law --check` 绿、7 个单元 active（掉线被看门狗拉起也算）；
- 账本里新增拒绝码没有恶化；
- 没违反「二」的禁忌；
- 若没做到：报告里**如实写「没做到」和原因**，不许写成做到了。

## 五、截止

绝对时刻：**2026-10-20 06:00 Asia/Shanghai**（＝ VM 本地 2026-10-20 00:00，CEST）。
到点由 `aios-goal-stop.timer` 强制停链，不靠单轮脚本自觉。
