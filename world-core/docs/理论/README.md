## 四、三层分工（书 ＞ 规格 ＞ 流程）

| 层 | 谁 | 只回答 | 冲突时 |

| **1 书（理念）** | 本树的正件 | 这一层应当是什么、今天做到几分、还剩什么没定 | **书赢** |
