## 〇、一把尺子：五级台阶（判据式）

| 级 | 名 | 达到它要有什么（判据） |
|---|---|---|
| **L1** | 能用嘴问 | 系统内有 AI 入口；★ AI **不改**系统 |
| **L2** | 能动手 | AI 能执行系统动作；★ **有审批或回滚**兜底 |
| **L3** | 运行环境治理 | 沙箱 ＋ 工具／技能**签名或鉴权** ＋ **可观测** ＋ 记忆分区 ＋ 快照回滚 |
| **L4** | 系统级策略与证据 | **策略内核**（谁能做什么，不由应用自管） ＋ **只追加账本** ＋ **成文不变量** |
| **L5** | 语义权威 | 动作名／实体的**权威来源＝形式本体**；**未登记即拒**；界面与投影同源 |

★ **台阶问的是「有没有」，不是「好不好」**：L3 做得再深，也不等于 L4。

## 二、ANOLISA（阿里云 Agentic OS）—— L3 扎得深，摸到 L4 的边

**它是什么**（厂商自述）：阿里云基于自研 Alibaba Cloud Linux 4 做的**面向 Agent 的衍生操作系统**，与标准版共享同一内核；`yum/dnf`、`systemctl`、`bash` 行为与标准版一致；文档更新于 **2026-09-10**；免费镜像、云资源另计；自带 `anolisa doctor` / `anolisa status`。

**它自己分的四层**（厂商自述，逐层都有真东西）：

| 层 | 组件 | 干的事（厂商逐字要点） |
|---|---|---|
| 交互 | **cosh** | 取代默认 Shell，原生托管 bash/zsh，**同一终端接收自然语言任务** |
| 交互 | **OS Skills** | 内置技能包机制；Agent 靠「Skill 说明书」获得部署／运维／诊断／可观测等动手能力 |
| 运行时 | **AgentSecCore** | 打 Agent 生命周期威胁（Prompt 注入、动态代码执行、技能安全、**意图偏离**、环境风险）；「感知—决策—阻断—**溯源**」闭环；**技能数字签名 ＋ 加密，调用前强制身份鉴权 ＋ 完整性校验 ＋ 硬件级安全沙箱** |
| 运行时 | **AgentSight** | **基于 eBPF** 的 Agent 可观测：零修改捕获 **LLM API 调用、Token 消耗、进程行为** |
| 运行时 | **AgentMemory** | 文件形态的**记忆 MCP 服务器**：持久、可搜索、**沙箱保护**；BM25＋向量混合检索；跨会话延续 |
| 运行时 | **ws-ckpt** | 工作区**快照与一键回滚**（可每轮问答自动快照） |
| 运行时 | **SkillFS** | **FUSE 按需挂载技能**：只暴露当前所需子集，可隐藏技能、可回退可信快照 |
| 运行时 | **Tokenless** | 上下文压缩 ＋ 命令过滤，降 Token 消耗；可挂 cosh／OpenClaw／Hermes／Claude Code／Codex／Qoder／Qwen Code |
| 基础 | Alinux4 | 内核优化、云原生等全部能力 |

**它做到的那一格（对台阶）**：技能**签名＋鉴权＋完整性校验**（≈「谁能做什么」）、**eBPF 溯源**（≈「留痕」）、**快照＋一键回滚**（≈「可回退」）、**沙箱记忆**（≈「记忆分区」）⇒ **稳稳落在 L3**。

**它缺的那一格（这是要点）**：

| 台阶要的 | 它有什么 | 判定 |
|---|---|---|
| 权威来源＝本体 | **SKILL.md 说明书**（读时按目标发行版即时编译） | ★ 说明书 ≠ 世界模型；**未见「未登记即拒」这类语义闸门** |
| 只追加账本 | AgentSight 的**监控／溯源** | ★ 是监控读数，**不是只追加账本**；**未见证据等级** |
| 成文不变量 | 未见 | ★ 未见「不变量／宪法」那一层，也未见「AI 只提议不执行」的硬分界 |
| 语义一致 | 全文档未提本体／语义层 | ★ **未见** |

**限制**：① 形态是**云上镜像**（ECS，仅 x86）；② 是**厂商产品**，不是可当底座的社区发行版 —— 拿它做我们自己的底座这条路不通；③ 「四层纵深安全」「首个 Agent-first 操作系统」是**厂商话术**，★ **未实测**。

## 三、Linux-AI OS 1.0「Star」—— L2

**它是什么**：创始人 **Kevin Richards**；基于 **LMDE 7（Linux Mint Debian Edition）＋ Cinnamon**；用 **Ollama／Llama 跑本地模型**；面向「从 Windows 迁过来、几乎没用过 Linux 的人」。

**AI 干了什么**：AI 应用安装器（按用途替你挑软件）、备份与还原中心、控制中心、系统优化器、欢迎向导；★ 并能**替用户执行命令**。

**短板**：① 被评测者直接点出「**不是第一个 AI 发行版**，而且**官网页面自相矛盾**」；② 个人维护；③ **无策略、无审计、无语义层**。

**它证明了一件事**：桌面发行版塞一个本地 AI 助手，**门槛已经很低**了 —— 这类件**不构成我们的对手**。

## 四、AILinux 26.04 —— L2–L3

**它是什么**：以 **Ubuntu 衍生**的桌面发行版（ISO 4.32 GiB，2026-09-27，官网给 SHA256），把 **ai-coder 1.4.3**（命令行＋图形 AI 操作员）＋ **TriForce**（登录、模型路由、MCP 工具、故障切换）＋ Nova AI 打包成产品；模型层可换（Mistral／NVIDIA NIM／Groq／Cerebras／Hugging Face／Ollama），带**模型故障切换**与**本地审批代理**。

**它的口号是关键**（厂商逐字）：**「AI 是操作员，不是操作系统」** —— Linux 保持是那个普通、可检查、可修复的 Linux。

**对照意义**：它**正好是我们要做的反面**——它把 AI 当**司机**；我们把 AI 当**世界里有一席之地的成员**（身份、许可、账）。★ 客户会拿它来比，所以书上要有一句明确的回答。

**两点警惕**：① 站点带商店／订阅／Google 登录，**控制面在别人云上**（与我方「本地、可审计」相反）；② 站点内容夹着明显的 AI 生成营销文（评论区成片无关广告）⇒ ★ **「有 ISO」不等于「产品能打」**。
