## §五 ★★★★★ 授权交给本体（★ 作者要的那件事）

★★ **做法**：★ 把 DSH 的【动手工具】在 profile patch 里 `disabled: true` ⇒ ★ 它**只剩** `world_*` ⇒ ★ **审批天然在本体** ✓
★ **本步（作者令「先改一部分」）只关三个**：`tool-bash`／`tool-pwsh`／`tool-fs`

★ **`tool-fs` 是什么（★ VM 现取）**：
```
/opt/nodejs/lib/node_modules/@deepseek-ai/dsh/node_modules/@deepseek-ai/dsh-tool-fs
描述: "Model-facing filesystem tools (read, write, edit) over the … filesystem seam (ctx.fs)"
注册: edit read read_image write
  read  → "Read a UTF-8 text file and return line-numbered content."
  write → "Create or fully replace a UTF-8 text file."
  edit  → "Edit an existing UTF-8 text file by replacing literal text."
  read_image → "Read a PNG/JPEG/WebP/GIF file and return the image itself."
```

★ **生效验证（★ 现取）**：
- `--dump-config` 逐字：`- id: tool-fs` ／ `name: '@deepseek-ai/dsh-tool-fs'` ／ **`disabled: true`** ✓
- DSH 列出的工具清单里 **没有 `bash`／`pwsh`／`read`／`write`／`edit`** ✓，**有 `world_query`／`world_ask`／`world_ui`** ✓
- ★ 让它「用 bash 跑 `ls /`」时它自述：★「**这个环境没有 bash**…我的能力全部来自**「世界本体」暴露的动作清单**」；★ `fs.list` → **「没有许可条文（`permissions.default = 'deny'` ⇒ 默认拒绝）」** ✓
