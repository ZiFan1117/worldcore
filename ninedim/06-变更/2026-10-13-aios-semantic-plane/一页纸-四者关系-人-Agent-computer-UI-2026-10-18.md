## ★ 一句话（全页结论）

> ★★★ **世界是中心（三本两点）：本体＝法律（允许有什么）／许可＝谁可以／账本＝事实（发生过什么）；门禁判、唯一入口写。**
> ★★ **人、Agent 是它的两个对等主体；computer 是它底下可换的承载（由载体代言）；UI 是人的那份读法与口——不是第三个主体，也不是人↔Agent 的中介。**

```
第4层  在场与接入    人 · agent · 程序            ← 主体（谁在跟世界说话）
```

## 五、两条链（书 §4.3／§4.4／§4.5）

```
写：人/Agent →（接入：口给身份）→（门禁：读本体+许可 → 裁）→（唯一写入口落笔）→ 账本
读：人/Agent →（接入）→（读法：从账本折出）→ 语言投影（给程序）／视觉投影（给人；UI 只摆不持状态）
```

三句硬引（逐字）：

1. **「身份由入口给出，请求说了不算。」**（§4.3）——13 的 `by`（谁发的）／`for`（为谁发的）＋ Permit 就是这句的落地（**未实现**）。
2. **「这几份读法之间的规矩只有一条：谁也不调用谁。」**；分叉信号里有一条：**「有人让 agent 直接读界面上显示的内容」**。（§4.4）
3. **「只写，不裁决。」**（§4.5，写侧的纪律；准不准做一律问门禁）
