# 说明：**多个进程同时让 UI 显示不同的东西，行不行**（2026-10-15）

> ★ **作者问（逐字）**：「**我现在是一个进程，让你这个 UI 来显示，那我如果是多个进程，让你 UI 同时显示不同的东西，你能行吗**」。
> ★ **一句答**：★★ **能 —— 协议本来就支持**（A2UI **天生是多表面的**：每个进程建自己的 `surfaceId`，各更新各的，互不覆盖）；★ **但今天这一套会互相盖**（三处缺口见 §三）。
> ★ **而且**：★★ **本体里已经有这一格了 —— `surface` 类**（§二）。

---

## §一 ★★ 为什么「能」：A2UI **天生就是多表面**的

| 机制 | 说明 |
|---|---|
| ★ `createSurface` | ★ **建一个表面**（带 `surfaceId`）—— ★ 我们实测里用的就是它（`surfaceId` = `world/system`） |
| ★ `updateComponents` | ★ **定向更新某一个表面**（只改那个 `surfaceId` 的元件） |
| ★★ 多表面 | ★★ **两个进程各建各的 `surfaceId` ⇒ 各改各的 ⇒ 协议层面不会互相覆盖** |

⇒ ★★ **「多个进程同时显示不同的东西」这件事，协议本身没有障碍。**

---

## §二 ★★★ 本体里**早就留好了这一格**（现取）

| `objects.surface`（`instance_mode: many`） | 类型 | ★ 它是干嘛的 |
|---|---|---|
| `name` | string | ★ 表面叫什么 |
| `role` | string | ★ **它是什么角色** |
| ★★ `order` | integer | ★★ **排第几**（★ 多表面布局要的就是它） |
| ★★ `visible` | bool | ★★ **可不可见**（★ 多表面仲裁要的就是它） |
| `retract_seq` | integer | ★ 撤回号（账里那一格） |
| `cells` | array(object) | ★ 表面里的格子 |

⇒ ★★★ **`order` ＋ `visible` 两格，正好就是「多个表面怎么排、谁看得见」** —— ★ **本体早就为「多个进程同时显示」准备过格了**（`many` ⇒ **本来就不止一个**）。

---

## §三 ★★ 但今天这一套**会互相盖**（三处缺口）

| # | 缺口 | 现取 |
|---|---|---|
| **1** | ★★ **渲染器是全量重画** | ★ 同盒 `实测-四进程与GUI渲染.md` §五 逐字登记：「**没做增量**（A2UI 的 `updateComponents` 可增量，★ **本件每帧都是全量重画**）」⇒ ★ **第二个进程一投，第一个的画面就被重画掉了** |
| **2** | ★★ **进程身份是自填的** | ★ `worldcore.rs` 里 `let by = v.get("by")…` ⇒ ★ **多进程投帧，分不清谁是谁** |
| **3** | ★★ **`surface` 没有「属于谁」这一格** | ★ 现取：`surface` 六格是 `name`／`role`／`order`／`visible`／`retract_seq`／`cells` —— ★ **没有 owner**（★ 对照：`port` 类**有** `owner_uid`）⇒ ★ **「谁拥有哪个表面」，本体今天答不出** |

## §四 ★ 要让它成真：补三格 ＋ 一个实验

| # | 补什么 | 在哪一层 | 今天有没有 |
|---|---|---|---|
| **1** | ★★ **渲染器按 `surfaceId` 增量更新**（★ A2UI 原生支持） | ★ 渲染器 | ★ **没有**（全量重画） |
| **2** | ★★ **身份不许自填**（走已定的「身份由本体给」） | ★ 协议 | ★ **没有** |
| **3** | ★★ **`surface` 补一格「属于谁」**（哪个个体拥有它） | ★★ **本体**（★ 动本体 ⇒ **只增可、改不行** ⇒ **待裁**） | ★★ **没有** |

## §五 ★★ 一个可实测的验收实验（会红的样子先写死）

```
实验：起【两个】个体进程（各投一个不同的 surfaceId），起一个渲染器
合格：★ 屏幕上【两个表面都在】—— 各占一块，按 surface.order 排
★★ 不合格（今天预期）：★ 只剩【后投的那一个】⇒ 这就是「全量重画」的铁证
```

★ **注意这条实验属于「呈现方向」**：★ **世界不变**（★ 两个表面都是纯显示时，本体**不介入内容**）—— ★ 只有当中某个动作**要改变世界**时，才走名字门。

## §六 ★ 本体在这件事里管什么（按已定口径，不越界）

| 管 | 不管 |
|---|---|
| ★ **谁拥有哪个表面**（`surface` 那一格） | ★ **画什么**（元件树） |
| ★ **这个进程是谁**（身份） | ★ **谁盖谁在像素上怎么实现**（★ 渲染器按 `order`／`visible` 排） |
| ★ **投过什么**（留痕） | ★ **怎么排好看**（呈现设计） |
