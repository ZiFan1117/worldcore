# 实测：**「注册（进）」与「经总线到独立执行体（出）」两条路跑通**（2026-10-17）

> ★ **作者令（逐字）**：「**先不用人点，先把前两条路完全跑通**」。
> ★★ **两条路都跑通了** —— ★ 读数见 §一。
> ★ 本件是**档案**（逐字收录两个 bin 的源码）；★ 可执行的副本在**载体 B**（VM 的 /root/bus/src/bin/）。

★★★ **三条要点**：
1. ★★ **进来的路（注册）**：★ 执行体启动 ⇒ 注册 11 条 ⇒ 落注册表 ⇒ **本体侧读回合并成 20 条在册表** ✓
2. ★★ **出去的路**：★ 本体过门（＋授权）⇒ **发到总线 `world/exec`** ⇒ **另一个进程收到** ⇒ 查映射表转成 `ls -l`／`ps` ⇒ 真执行 ⇒ 回 `world/exec/result` ⇒ **本体收到回话** ✓
3. ★★ **两边各落账**（4 笔、接链）✓

## 二、★ 本笔路上撞到的三件真事（都给登记）

| # | 现象 | 结论 |
|---|---|---|
| **1** | ★★ 第一次跑：★ 门**直接拒**（`NotPermitted`）—— 因为 `fs.list` 是**注册进来的**，★ 本体**没有授过它** | ★★★ **这不是缺陷，是那条命门**：★ **注册 ≠ 有权**（★ 授过才放行；★ 那个 bin 里显式授了一次，★ 真实里这一步是人给的） |
| **2** | ★★ 第二次跑：★ 卡在 `UnknownKind：fn.fs.list` —— `Exec` 第④步查的是**本体原文的函数面**，★ 注册进来的函数不在里面 | ★★ **注册面与函数面没接上** ⇒ ★ 本笔加了 `Registry::is_registered_function`（★ 见 §三） |
| **3** | ★★ 注册表**一直涨**（22 → 33 → 44 → 55 → 66 行）—— 每次启动注册都**追加** 11 行 | ★ **读回时后者覆盖**（`insert`）⇒ 语义对；★ **但盘上会膨胀** ⇒ ★ **待办**：★ 注册改成**只写变更**或**定期压实** |

## 三、★★★ 我第一版修错过一次（★ 被既有测试当场抓住）

| 项 | 内容 |
|---|---|
| ★ 我第一版的判据 | ★ 「`registry.function_of_action(action) == function_id`」⇒ 放行 |
| ★★ 为什么错 | ★ 那条判据只证明「**本体自己指向了它**」—— ★ 而**悬空引用**（★ 本体里 `function` 指向一个不存在的 `fn.X`）**恰好也满足它** ⇒ ★ **把该拒的放行了** |
| ★★ 谁抓住的 | ★ **既有测试** `engine::execute::tests::a_dangling_function_reference_is_refused`（★ 逐字断言「悬空引用该拒」）⇒ **test 红** |
| ★ 正确判据 | ★★ 「**注册面认领了它**」：★ `Registry::is_registered_function(function_id)`（★ `load_with_registration` 时把注册表那些 `function` 记进一格） |

## 四、executor_daemon.rs（逐字 · 独立执行体）

```rust
//! 独立执行体（T-255）：★ 它就是「那只手」—— 坐在总线的另一头。
//!
//! ★ 它干四件事：
//!   ① 【进来那条路】启动时**注册自己的动作**（从映射表）⇒ 落注册表 ⇒ 报到；
//!   ② 订阅 world/exec，收本体发来的 {action, params, by, trace};
//!   ③ **查映射表** ⇒ program+args ⇒ **真起进程**（不拼 shell）；
//!   ④ 回结果到 world/exec/result，并把这一笔**落账**（只追加）.
use std::time::Duration;

use aios_worldcore::core::types::{Admit, Who};
use aios_worldcore::engine::execute::{CommandRunner, Executor};
use aios_worldcore::engine::ledger::Ledger;

const ONT: &str = "/root/aios/crates/aios-ontology/data/ontology.json";
const MAP: &str = "/root/aios/crates/aios-ontology/data/command-map.jsonl";
const REG: &str = "/root/bus/registry.jsonl";
const LEDGER: &str = "/root/bus/ledger.jsonl";
const INTENT: &str = "world/exec";
const RESULT: &str = "world/exec/result";

/// ★ zenoh 的 ZBytes 没有 to_string。
fn as_text(z: &zenoh::bytes::ZBytes) -> String {
    String::from_utf8_lossy(&z.to_bytes()).into_owned()
}

fn main() {
    tokio::runtime::Builder::new_multi_thread()
        .enable_all()
        .build()
        .unwrap()
        .block_on(run());
}

async fn run() {
    // ① 【进来那条路】注册 + 报到
    match aios_worldcore::core::command_bridge::register_from_map(MAP, REG) {
        Ok(n) => println!("[执行体] ① 注册：映射表 {n} 条已登记 ⇒ 落 {REG}（★ 注册是一次性的、持久的）"),
        Err(e) => println!("[执行体] ① 注册被拒：{e}"),
    }

    let runner = CommandRunner::from_map(MAP).expect("build runner");
    let text = std::fs::read_to_string(ONT).expect("ont");
    let session = zenoh::open(zenoh::Config::from_env().expect("cfg"))
        .await
        .expect("open");
    let sub = session.declare_subscriber(INTENT).await.expect("sub");
    println!("[执行体] ② 起来了，订阅 {INTENT}（★ 本体发来的 action 从这里进）");

    loop {
        match tokio::time::timeout(Duration::from_secs(8), sub.recv_async()).await {
            Ok(Ok(s)) => {
                let txt = as_text(s.payload());
                println!("[执行体] 收到：{txt}");
                let v: serde_json::Value = match serde_json::from_str(&txt) {
                    Ok(v) => v,
                    Err(e) => {
                        println!("[执行体] 拒绝：不是合法 JSON（{e}）");
                        continue;
                    }
                };
                let action = v["action"].as_str().unwrap_or("").to_string();
                let who_name = v["by"].as_str().unwrap_or("world://unknown").to_string();
                let trace = v["trace"].as_str().unwrap_or("trace-0").to_string();
                let mut params = serde_json::Map::new();
                if let Some(o) = v["params"].as_object() {
                    params = o.clone();
                }
                let who = Who::new(who_name.clone());
                // ③ 查映射表 ⇒ 真跑
                let outcome: Admit<String> = runner.run(&action, &who, &params);
                let (ok, body) = match outcome {
                    Ok(out) => (true, out.chars().take(200).collect::<String>()),
                    Err(e) => (false, format!("{e}")),
                };
                println!("[执行体] ③ 跑 {action} ⇒ ok={ok}；body 头：{}", body.replace('\n', " ⏎ "));
                // ④ 回结果
                let reply = serde_json::json!({
                    "trace": trace, "action": action, "ok": ok, "body": body
                });
                let _ = session.put(RESULT, reply.to_string()).await;
                println!("[执行体] ④ 已回 {RESULT}");
                // ④b 落账（只追加）
                drop(text.clone());
                if let Ok(mut l) = Ledger::load_file(&text, LEDGER) {
                    let mut p = serde_json::Map::new();
                    p.insert("action".to_string(), serde_json::json!(action));
                    p.insert("trace".to_string(), serde_json::json!(trace));
                    p.insert("ok".to_string(), serde_json::json!(ok));
                    match l.append_persisting(LEDGER, &who, "act", format!("exec:{action}"), p) {
                        Ok(seq) => println!("[执行体] ⑤ 落账：第 {} 笔（{LEDGER}）", seq.0),
                        Err(e) => println!("[执行体] ⑤ 落账被拒：{e}"),
                    }
                }
            }
            Ok(Err(e)) => println!("[执行体] 订阅出错：{e}"),
            Err(_) => {
                println!("[执行体] 8 秒没有新 action，退出");
                break;
            }
        }
    }
}

```

## 五、worldcore_bus.rs（逐字 · 本体那一侧）

```rust
//! 本体进程那一侧（T-255）：★ 过三道门 ⇒ **经总线把 action 发给执行体** ⇒ 等结果 ⇒ 落账。
//!
//! ★★★ 它就是作者说的那一段：★「本体发一条命，经总线发一条给这个执行体」。
//! ★ 出向口就在 BusExecutor：★ Exec（过门）⇒ BusExecutor::run（发消息 + 等结果）。
use std::sync::mpsc;
use std::time::Duration;

use aios_worldcore::core::registry::Registry;
use aios_worldcore::core::types::{Admit, Reason, Refuse, Who};
use serde_json::Map;
use aios_worldcore::engine::execute::{Exec, Executor};
use aios_worldcore::engine::ledger::Ledger;
use aios_worldcore::governance::Governance;

const ONT: &str = "/root/aios/crates/aios-ontology/data/ontology.json";
const REG: &str = "/root/bus/registry.jsonl";
const LEDGER: &str = "/root/bus/ledger.jsonl";
const INTENT: &str = "world/exec";
const RESULT: &str = "world/exec/result";

/// ★ zenoh 的 ZBytes 没有 to_string（★ 与 gui_renderer 同法）。
fn as_text(z: &zenoh::bytes::ZBytes) -> String {
    String::from_utf8_lossy(&z.to_bytes()).into_owned()
}

/// ★★ **出向口**：★ 把「要执行的一件 action」经总线发出去，然后等执行体回话。
struct BusExecutor {
    session: zenoh::Session,
    rx: mpsc::Receiver<String>,
}

impl Executor for BusExecutor {
    fn run(&self, action: &str, who: &Who, params: &Map<String, serde_json::Value>) -> Admit<String> {
        let trace = format!("t-{}", action);
        let msg = serde_json::json!({
            "action": action, "by": who.name(), "trace": trace, "params": params
        });
        // ★ 发出去（这是【本体经总线】那一跳）。
        let s = self.session.clone();
        let payload = msg.to_string();
        let sent = tokio::task::block_in_place(|| {
            tokio::runtime::Handle::current().block_on(async move {
                s.put(INTENT, payload).await
            })
        });
        if sent.is_err() {
            return Err(Refuse::new(Reason::StorageUnavailable { path: INTENT.to_string() }, "<发不出去>"));
        }
        println!("[本体] ③ 已把 {action} 发到总线 {INTENT}（★ 不是同进程调用了）");
        // ★ 等执行体回话。
        match self.rx.recv_timeout(Duration::from_secs(6)) {
            Ok(body) => Ok(body),
            Err(_) => Err(Refuse::new(Reason::StorageUnavailable { path: RESULT.to_string() }, "<执行体没回话>")),
        }
    }
}

fn main() {
    tokio::runtime::Builder::new_multi_thread()
        .enable_all()
        .build()
        .unwrap()
        .block_on(run());
}

async fn run() {
    let text = std::fs::read_to_string(ONT).expect("ont");
    // ★★ 【在册表 ＝ 本体 ＋ 注册表】—— 注册那一半由执行体启动时写的。
    let reg = Registry::load_with_registration(&text, REG).expect("registry");
    let mut gov = Governance::from_ontology(&text).expect("governance");
    println!(
        "[本体] ① 在册表：本体 {} 条 ＋ 注册表 ⇒ 合计 {} 个动作",
        Registry::load(&text).expect("ont").action_kinds().len(),
        reg.action_kinds().len()
    );
    // 结果那条回话的路
    let (tx, rx) = mpsc::channel::<String>();
    let session = zenoh::open(zenoh::Config::from_env().expect("cfg"))
        .await
        .expect("open");
    let sub = session.declare_subscriber(RESULT).await.expect("sub");
    let tx2 = tx.clone();
    tokio::spawn(async move {
        while let Ok(s) = sub.recv_async().await {
            let _ = tx2.send(as_text(s.payload()));
        }
    });
    println!("[本体] ② 订阅 {RESULT}（执行体的回话从这进）");

    // ★ 走一遍：报一个在册动作。
    let who = Who::new("world://user/zhang");
    let actions: Vec<String> = std::env::args().skip(1).collect();
    // ★★★ **注册 ≠ 有权** —— ★ 注册进来的动作本体【没有】授过它 ⇒ 门会拒。
    //   ★ 所以授权要在建 Exec【之前】做完（★ 借 &gov 之后不能再改 gov）。
    //   ★ 真实里这一步由人给（★ 本体 permissions.grants 那一格）。
    for action in &actions {
        gov.grant(&who, action);
        println!("[本体] ①b 授过：{} ⇒ {}（★ 注册 ≠ 有权：不授就拒）", who.name(), action);
    }
    let port = BusExecutor { session: session.clone(), rx };
    let exec = Exec::new(&reg, &gov, port);
    for action in actions {
        let params = Map::new();
        // 门：名字（在册）＋ 治理（授权）都在 Exec::run 里过。
        let verdict = exec.execute(&action, &who, &params);
        match verdict {
            Ok(body) => println!("[本体] ④ {action} 回话（{} 字节）：{}", body.len(), body.replace('\n', " ⏎ ")),
            Err(e) => println!("[本体] ④ {action} 被拒／失败：{e}"),
        }
        // ⑤ 本体这一侧也落账（谁让做的 ＋ 因果）
        if let Ok(mut l) = Ledger::load_file(&text, LEDGER) {
            let mut p = Map::new();
            p.insert("action".to_string(), serde_json::json!(action));
            p.insert("who".to_string(), serde_json::json!(who.name()));
            match l.append_persisting(LEDGER, &who, "act", format!("intent:{action}"), p) {
                Ok(seq) => println!("[本体] ⑤ 落账：第 {} 笔", seq.0),
                Err(e) => println!("[本体] ⑤ 落账被拒：{e}"),
            }
        }
    }
    println!("[本体] 完成，退出");
}
```
