# 说明：**AIOS-FS（`/aios` 语义对象存储）准备干什么**（2026-10-15）

> ★ **作者问（逐字）**：「**AIOS-FS：/aios 语义对象存储他准备干什么**」。
> ★ **一句答**：★ 它要**取代 POSIX 当权威存储** —— ★ 逐字：「**AIOS-FS is the native semantic filesystem mounted at `/aios`. Files are versioned objects, paths are query-backed views, and every write has intent, policy, provenance, rollback, and evidence linkage. AIOS-FS is authoritative storage, not a sidecar over POSIX.**」
> ★ 本件**现取**：上游 L2 规格 `002.AI-OS.NET--SPECREV.2/L2_AIOS_FS/00_overview.md` ＋ `crates/aios-fs/src`（**25 件**）。

---

## §一 ★★★ 一句话：它要把「文件系统」改造成「版本化对象 ＋ 查询视图」

| 传统文件系统 | ★ AIOS-FS 要做的 |
|---|---|
| **文件**（就地覆盖） | ★ **版本化对象**（★ 逐字不变式：「**Committed data is never overwritten in place; writes create new versions**」） |
| **路径**（目录树就是身份） | ★ **查询支撑的视图**（★ 逐字：「**paths are query-backed views**」；★ 且「**Semantic views are not authoritative storage identity**」） |
| **写就是写**（没有别的） | ★★ **每一次写都带：意图／策略／来源／回滚／证据联动**（★ 逐字：「**every write has intent, policy, provenance, rollback, and evidence linkage**」） |
| 索引坏了就坏了 | ★ **索引可重建**（★ 逐字：「**Semantic indexes are rebuildable from object metadata**」） |
| 崩溃/恢复要人 | ★ **恢复不依赖认知核**（★ 逐字：「**Recovery can inspect objects without the Cognitive Core**」） |

---

## §二 ★★ 它的六条层不变式（逐字，`L2/00_overview.md`）

1. ★ **Filesystem truth must not depend on L7 UI**（文件系统的真相不许依赖界面）；
2. ★★ **Committed data is never overwritten in place; writes create new versions**（已提交的数据**永不就地覆盖**；写产生新版本）；
3. ★★ **Pointer moves promote state; rollback moves a pointer to a previous verified version**（**指针移动推进状态**；回滚＝把指针移回上一个**已验证**版本）；
4. ★★ **Semantic views are not authoritative storage identity**（**语义视图不是权威存储身份**）；
5. ★ **Semantic indexes are rebuildable from object metadata**（语义索引可由对象元数据**重建**）；
6. ★ **Recovery can inspect objects without the Cognitive Core**（**恢复不需要认知核**）。

★★ 第 2／3／4 条与我们已做的事**正面撞上**：★「永不就地覆盖」↔ 我们**账只追加**；★「指针移动推进状态」↔ 我们 store 里的 **`Pointer{current, previous}` ＋ `as_of()`**；★「语义视图不是权威身份」↔ 我们**呈现维／事实维**那条口径。
