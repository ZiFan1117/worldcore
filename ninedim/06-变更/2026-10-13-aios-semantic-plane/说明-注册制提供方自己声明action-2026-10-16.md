# 说明：**注册制 —— 提供方自己声明 action**（作者凝练 · 2026-10-16）

> ★ **作者话（逐字）**：「**函数在注册的时候，就是在这个软件注册的时候，就要提供对外的接口 action 啥的。我觉得这种是可注册的，不是本体。本体只能说有一个 action 列表，不能说是完全定义了它有哪些 action，action 和其他的肯定是不一样的。对，它会提供一些接口，就像那个 MCP 一样，对吧？所以说无论是 CPU 那一侧底层这些工具，还是说开发的一些软件，都应该是这种形式。然后呢，我们用本体，然后来调动，包括这个 GUI 也是一样的，我感觉它也应该抽象成一个个体，然后注册一些 action，让其他人去调用它，对不对，是达到一个这样的目的，前后端也分离了。整个就围绕着本体这套就全部建圆满了，是这么个逻辑**」。
> ★ **一句判断**：★★★ **这个凝练对，而且比我前面的说法准** —— ★ 我此前说「把命令行**映射**成函数放进本体」（★ 像**我们替它编目**）；★ 你说的是「**提供方自己注册**」⇒ ★★ **注册制，不是编目制**。

---

## §一 ★★★ 注册制 vs 编目制（★ 这一字之差，落点全不同）

| | ★ 编目制（我前面的说法） | ★★★ **注册制（你的凝练）** |
|---|---|---|
| 谁**定义**有哪些 action | ★ **我们**（替所有东西编一份目录） | ★★ **提供方自己**（★ 底层工具、软件、GUI 各自注册） |
| 本体里那个列表是什么 | ★ **一份完整的定义** | ★★ **一份「登记结果」** |
| 完备性 | ★★ **不可能完备**（★ 谁也不可能替全世界的软件列完） | ★★ **不需要完备** —— ★ **不注册 ＝ 不存在** |
| 参数形状谁给 | ★ 我们猜／去读 | ★★ **提供方自己声明**（★ 它自己最清楚） |
| 本体干什么 | ★ 定义 ＋ 判定 | ★★ **只判定**（在册吗／配不配） |

★★★ **所以你那句「本体只能说有一个 action 列表，不能说是完全定义了它有哪些 action」—— ★ 精辟。**

## §二 ★★★ 三个外部先例都印证（★ 其中一个有逐字）

### §二·1 ★★★ P：**这就是注册制**（逐字现取 `ontology.py`）

```python
@dataclass
class Ontology:
    """Master registry — equivalent to a Foundry Ontology."""   # ★★ 逐字：登记簿
    object_types: dict[str, ObjectType]
    link_types:   dict[str, LinkType]
    action_types: dict[str, ActionType]
    functions:    dict[str, OntologyFunction]
    interfaces:   dict[str, Interface]

    def register_object_type(self, ot)   -> None: self.object_types[ot.type_id] = ot
    def register_link_type(self, lt)     -> None: …
    def register_action_type(self, at)   -> None: self.action_types[at.action_id] = at   # ★★ 注册 action
    def register_function(self, fn)      -> None: self.functions[fn.function_id] = fn    # ★★ 注册函数
    def register_interface(self, iface)  -> None: …

    def validate_ontology(self) -> list[str]:
        """Check referential integrity. Returns list of error messages."""   # ★ 引用完整性
```

⇒ ★★★ **P 的本体自述就是「Master registry」（登记簿）＋ 五个 `register_*`** —— ★★ **提供方 register 进来，本体只是那本簿子** ✓✓ ✓
★ 而且★ **`validate_ontology()` 查引用完整性** —— ★ 与我方判据 **C7** 同形。

## §五 ★★★ 一条必须点明（★ 防止走过头）

> ★★★ **注册 ≠ 有权。**

| 注册给了什么 | ★ **没给**什么 |
|---|---|
| ★「**我有这个能力**」 | ★★ **没有说「谁可以用它」** |
| ★ 它可以**声明** `required_roles`（★ 那是**要求**） | ★★ **判定仍在【门】**（★ 否则**谁注册谁说了算 ＝ 第二权威**） |

★ **一句话**：★ **注册是「登记能力」；能不能用要过三道门。**
★ **规格里已有一条同族的分寸**（★ `handbook.spec.md`）：★「系统 SHALL NOT 把裁剪后的手册当成权限判定」—— ★ 本件再加一条同族的：★ **注册进来的声明也不当权限判定**。
