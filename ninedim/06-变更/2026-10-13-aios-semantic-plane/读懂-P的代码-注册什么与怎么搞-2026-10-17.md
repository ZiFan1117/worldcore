## §一 ★★★ 它自述是什么（逐字）

★ `docs/architecture.md` 逐字：★ **「Three-Layer Model」** —— ★ Palantir Foundry 的**三层本体架构**：

| ★ 层 | ★ 逐字 | ★ 装什么 |
|---|---|---|
| ★★ **Semantic Layer（语义层）** | ★「ObjectType**: Schema for entities (Asset, Technician, etc.)」／「Property: Fields with types」／「LinkType: Typed relationships」／「Interface: Polymorphic shapes」 | ★ **类型与形状** |
| ★★ **Kinetic Layer（动力层）** | ★「ActionType**: Executable actions with parameters, validation rules, and effects**」／「OntologyFunction: Server-side business logic」／「ActionExecutor: Runs actions with validation and audit」／「ValidationRule: Python expressions evaluated at runtime」 | ★ **动作与执行** |
| ★★ **Dynamic Layer（动态层）** | ★「Roles & Permissions」／「Markings: Data classification」／「AuditLog: Immutable trail of all actions」 | ★ **权限与审计** |
| ★ **Export Bridge（★ 它独有的）** | ★「OWLExporter／SHACLGenerator／OntoGuardBridge／MCP」 | ★ 导出与对外 |

★ **数据流五步（逐字）**：★「1. Define Ontology (schema) → 2. Create instances in ObjectStore → 3. Query via OntologyQuery (navigate links, filter) → 4. Execute actions via ActionExecutor → 5. Export to OWL/SHACL for interoperability」

## §三 ★★★★ 它**注册什么**（★ 本件核心答案）

★★★ **一张表说清 —— 5 个 `register_*`，注册的全是【类型的声明】**：

| # | ★ 注册什么 | ★ 类 | ★ 有哪些格（逐字） |
|---|---|---|---|
| **1** | ★★ **对象类型** | `ObjectType` | ★ `type_id`／`display_name`／`description`／**`properties: dict[str, Property]`**／`primary_key`／`interfaces`／`datasource`／`metadata` |
| **2** | ★ **关系类型** | `LinkType` | ★ `link_id`／`display_name`／`source_type`／`target_type`／**`cardinality`**（one_to_one／one_to_many／many_to_many）／`reverse_name`／`properties` |
| **3** | ★★ **动作类型** | `ActionType` | ★ `action_id`／`display_name`／**`parameters`**／**`validation_rules`**／**`effects`**／**`required_roles`**／`audit_enabled` |
| **4** | ★ **函数** | `OntologyFunction` | ★ `function_id`／`input_types`／`output_type`／**`implementation`**（★ 真函数） |
| **5** | ★ **接口** | `Interface` | ★ `interface_id`／`required_properties` |

★★★ **⇒ 关键：★ 它注册的不是「装了什么程序」，★ 而是「这个世界允许有什么形状」。**
★★★ **⇒ 而它【不需要】注册程序** ★ —— ★ 因为★ **它的动作靠 `effects` 改数据**（`ActionEffect(effect_type, target, changes)`）★ **不起进程** ✓

★ **一个动作的完整声明（逐字）**：
```python
o.register_action_type(ActionType(
    action_id="EscalateAsset",
    parameters=[ActionParameter("asset_id", PropertyType.STRING),
                ActionParameter("priority", PropertyType.STRING, options=["LOW","MEDIUM","CRITICAL"])],
    validation_rules=[ValidationRule("r1", "asset.get('status') != 'decommissioned'", "Cannot escalate decommissioned asset")],

```

## §五 ★★★★ `execute()` 的**七步**（★ 逐字，`action_executor.py:32-127`）

| ★ 步 | ★ 逐字 | ★ 干什么 |
|---|---|---|
| **①** | ★ `at = self.ontology.action_types.get(action_type_id)` ★ `if not at: return 「Unknown action type」` | ★★ **查注册表 —— 不在册就拒** ✓ |
| **②** | ★ `if executed_by_roles is not None and at.required_roles: if not any(r in executed_by_roles for r in at.required_roles)` | ★ **查角色 —— 不够就拒** ✓ |
| **③** | ★ `context = dict(params)` ＋ `if context_resolver: context.update(resolved)` | ★ **建上下文**（★ 把引用的对象解出来） |
| **④** | ★ `result = at.validate(context)` ★ `if not result.valid: 写账(成功=False) → return` | ★★ **校验**（参数 ＋ 规则）★ **失败也写账** ✓ |
| **⑤** | ★ `for effect in at.effects: self._apply_effect(...)` ★ `except: 写账(失败) → return` | ★★ **应用效果**（改对象库） |
| **⑥** | ★ `entry = AuditEntry(..., success=True); eid = self.audit.append(entry)` | ★★ **写账（成功）** ✓ |
| **⑦** | ★ `return ActionResult(success=True, effects_applied=..., audit_entry_id=eid)` | ★★ **返回，★ 带账 id** ✓ |

★★★ **⇒ 三处值得学**：★ ① **查注册表是【第一步】**；★ ② **成功/失败【都写账】**；★ ③ **返回里【带 `audit_entry_id`】** ✓
