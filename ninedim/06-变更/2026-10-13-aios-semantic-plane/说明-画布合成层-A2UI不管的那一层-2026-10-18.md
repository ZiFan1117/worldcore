## §一 ★ 核实的结论（现取，2026-10-18）

### §一·1 A2UI 的 `createSurface` **只有四个字段**（★ genui `a2ui_schemas.dart` 逐字）

```dart
createSurfaceSchema() => S.object(
  properties: {
    'surfaceId':     S.string(description: 'The unique ID for the surface.'),
    'catalogId':     S.string(...),
    'theme':         S.object(...),
    'sendDataModel': S.boolean(...),
  },
  required: ['surfaceId', 'catalogId'],
);
```

★★ **⇒ 没有 `layout`、没有 `rect`、没有 `z`、没有 `position`。**

### §一·2 A2UI 的消息**只有四种**（★ `a2ui_core` `messages.dart` 逐字）

```dart
const messageBodyKeys = {
  'createSurface', 'updateComponents', 'updateDataModel', 'deleteSurface',
};
```

★★ **⇒ 没有 `setLayout`／`showSurface`／`retractSurface`／`moveSurface`。**

### §一·3 genui 的 `lib/src/widgets/` **只有三个文件**（现取）

```
fallback_widget.dart ／ surface.dart ／ widget_utilities.dart
```

★★ **⇒ 没有 compositor／stack／layer 之类的多画布合成件。**

### §一·4 a2ui.org 的 v0.9.1 协议页（现取 200，100,000 字节）

★ 全文检索 `position` 只命中【导航目录】；`surfaceId` 的例子是**一个 session 一个 surface**：

```
Server->>+Client: 1. createSurface(surfaceId: "main")
Server->>+Client: 2. updateComponents(surfaceId: "main", components: [...])
Server->>+Client: 3. updateDataModel(surfaceId: "main", path: "/user", value: "Alice")
Client->>+Server: action(name: "submit", context: {...})
```

★★★ **⇒ 一句话：A2UI 把【一张 surface 铺满它的容器】当作前提；多张怎么摞，规范【不写】。**

## §二 ★ 所以我们补的是什么（三层，别混）

| ★ 层 | ★ 归谁 | ★ 管什么 | ★ 是标准吗 |
|---|---|---|---|
| **① 画布【内部】** | **A2UI ＋ genui** | 组件树（Column／Row／Card／Text…）、数据绑定、动作 | ★ **是标准** ✓ |
| **② 画布【之间】** | ★★ **我们的扩展（`layout`）** | 谁、第几层（`z`）、摆哪（`rect`）、激活（`active`）、模态（`modal`） | ★★ **不是标准，是我们补的** ✗ |
| **③ 叠的动作** | ★★ **呈现（`presentation`）** | 按 `layout` 把此刻 `shown` 的画布叠成【合成清单】 | ★ 我们的实现 |

### §二·1 `layout` 的形状（我们定的）

```json
{"layout": {"layers": [
  {"surface": "surface/desktop-zhang", "z": 0, "active": true},
  {"surface": "surface/agent-dsh",     "z": 10, "rect": [16, 64, 600, 400]},
  {"surface": "surface/confirm",       "z": 100, "modal": true}
]}}
```

★ 它**放在帧的顶层**（和 `messages` 并列），★ **不塞进 A2UI 的 message**（不污染协议）。

### §二·2 合成器干什么（`presentation_process.py` 的 `compose()`）

1. 取 `layout.layers`
2. 按 `surface` 查 `shown` 表（此刻在的才画；不在的跳过）
3. 按 `z` 排序
4. 推 `{"t":"layout", "layers":[{surface,z,rect,active,modal,frame}]}` 给渲染器

★★ **⇒ 它【不布局、不裁决、不持状态】**（本体 `presentation` 定义逐字）。

### §二·3 渲染器干什么（`render_main.dart` 的 `_onLayout`）

1. 收 `layers`
2. 每层：`genui.Surface(surfaceContext: ctl.contextFor(sid))`
3. `rect` 有 ⇒ `Positioned`；没有 ⇒ `Positioned.fill`
4. `Stack` 摞起来

★★ **⇒ 渲染器【只摆、不决定】—— ★ 「摆」的输入就是 `layout`。**

## §三 ★ 为什么必须补这一层（三条）

1. **不补就没有「多画布」**：★ 一个 surface 铺满 ⇒ 桌面上就没法再叠 agent 的窗口。
2. **不补就不能「换人」**：★ 换人 = 甲的画布 `retract`、乙的 `show`；★ 那需要【一个地方】记住此刻有哪些、怎么摞。
3. **不补就违反四归属**：★ 文档说「摆放归个人空间」—— ★ 而「摆放」正是 `layout`。

---

## §四 ★ 本件没有做的事（如实）

- ★ **没改 A2UI 的任何东西**（genui／a2ui_core 原封不动）✓
- ★★ **`layout` 没有提交给 A2UI 社区** —— 那是我们的私有扩展 ⚠
- ★★★ **外部若不认 `layout`，渲染器可以忽略它**（★ 我们的渲染器用，别人的不用）✓
- ★ **`rect` 的坐标原点／单位没写进规范** —— 现在是【像素、左上角原点】⚠

## §五 ★ 没证的（如实）

1. ★ **「A2UI 规范没写多 surface 叠」** —— ★ 已核 v0.9.1 协议页 ＋ genui/a2ui_core 源码（§一）✓
2. ★★ **「v1.0 会不会写」** —— ★ **没查** ⚠
3. ★★ **「别的渲染器（React/Lit/Flutter GenUI 社区）有没有自己的 layout 约定」** —— ★ **没查** ⚠
4. ★ **`layout` 的 `rect` 语义（像素/左上原点）** —— ★ **是我们定的**，★ 不是标准 ⚠
