# _索引 · ninedim/records/模板

**本夹是什么**：模板：七类空白表单（`01-策划类`…`07-配置与发布类`）。

## 归哪几件

| 件 | 是什么 |
|---|---|
| `01-策划类/` | 子夹：策划类模板 |
| `02-需求类/` | 子夹：需求类模板 |
| `03-设计类/` | 子夹：设计类模板 |
| `04-实现类/` | 子夹：实现类模板 |
| `05-测试类/` | 子夹：测试类模板 |
| `06-评审类/` | 子夹：评审类模板 |
| `07-配置与发布类/` | 子夹：配置与发布类模板 |

## 规矩

- **深度封顶**：工程域下最多 2 层夹，第 3 层只放件；要再分就用文件名前缀。
- **件名口径**：`<类>-<名>.md`（如 `设计-架构说明.md`）或 `<能力>.spec.md`。
- **正文只有一份**：改动就地覆盖；改前／改后进 `06-变更/<变更号>/改动对照.md`；未批的进 `07-待审/`。
- **本夹不再建夹**（例外：`06-变更/<变更号>/`、`07-待审/<变更号>/` 这两个档案盒）。
- **一份索引**：本件是本夹**唯一的**索引；同夹不许再放第二份 `README.md` 之类当索引用。

> ⚠️ 七个类夹是**第 3 层夹**（`ninedim/records/模板/<类>/`），按深度封顶应塌平成文件名前缀 ⇒ **待整**。
