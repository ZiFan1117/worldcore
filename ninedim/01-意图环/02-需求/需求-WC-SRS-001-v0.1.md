**明确不在本版范围**（防止范围蔓延，逐条列出以便评审时一眼看见）：

### 1.3 术语与缩略语

| 术语 | 含义 |
|---|---|
| **语义事件** | 世界的唯一真相载体，`change` / `act` / `notice` 三家族之一，纯文本 JSON Lines |
| **信封（envelope）** | 事件的外层字段：`world,kind,id,seq,at,actor,flags,body`（+ 可选 `to,trace`） |
| **信纸（body）** | 家族特定的载荷（如 `change` 的 subject/path/before/after） |
| **读模型 / 投影** | `state = fold(events[0..seq])`；**派生物**，可随时删掉重算 |
| **本体（ontology）** | 词表 + 合法性规则 = 世界的**法律** |
| **门禁（gate）** | 事前拦截动作的检查点；**不可绕过**是本项目的硬分界 |
| **账本（ledger）** | 只追加的语义事件文件；**格式稳定、内容纯文本** |
| **被管者（managed actor）** | 被门禁管着的主体（人、agent 等）；与之相对的是**核心**——法律与真相的存放处。**被管者对法律与账本不得有写权限**（见 `REQ-F-015`） |
| **主体（actor）** | 世界内身份字符串，形如 `world://user`、`world://agent/1`；**身份不来自请求自称**——通道侧由内核经套接字属主与权限给出（一套接字一身份）。见 `REQ-F-025` |
| **能力（capability）** | `act` 要声明的动作名（如 `notice.mute`）；策略里**未声明的能力一律不放行**（**默认拒绝**，不是默认允许） |
| **不可逆（irreversible）** | 策略中 `reversible:false` 的能力等级；v1 **只允许 `irreversible_actors` 列出的主体执行**，白名单外一律 `AwaitApproval`，且理由明说**v1 没有审批通道**（`DEBT-07`） |
| **留痕（trace-keeping）** | 动作不论放行还是拒绝都必须留下可读记录：放行落 `act` 事件，拒绝落 `gate.rejected` / `gate.awaiting-approval` / `gate.write-rejected` 的 `notice` 流水 |
| **投递（delivery）** | 一条事件按收件人字段 `to` 被送达的动作；`to` 缺省（空）= **广播**。**已实现**（★ 2026-09-28 订正：原写"v1 未实现：`to` 在 `src/` 与 `tests/` 中零读写"——**那句在 2026-09-28 起不成立**）：`src/common/delivery.rs` 读 `to`（带 `to` 只送该收件人、无 `to` 即广播），断言 `scripts/test/delivery.rs` 的 `d01`–`d08`（含正控 `d04`）；见 `REQ-F-023` |
| **排版可审计（auditable layout）** | 视觉投影是给人的，但排版是**机器可核对**的契约（2 空格主体行 / 6 空格 `路径 = 值` 字段行）；改动需走 R5。见 `REQ-F-019` |
| **同源率** | 质量目标：抽查的投影事实中"能在读模型里查到同一 `(主体,路径,值)`"的比例。**目标值【候选】，待人工**（见 §6） |
| **事实可回溯率** | 质量目标：抽查的投影事实中"能沿账本反查到产生它的那条事件"的比例。**目标值【候选】，待人工**（见 §6） |

## 二、总体描述

### 2.1 产品定位（一句话）

**不是应用，是地基**：一个世界的"存 / 传 / 显 / 管 / 载 / 进"里，
本项目负责**存（账本+本体）· 传（总线）· 显（投影）· 管（门禁）**，
`载` 采购 Linux，`进` 买算力。**载体的态度**：它只知道启动这个组件，不知道它是什么。

### 2.2 用户与角色

|---|---|---|
| 人（世界的主人） | 我说过什么、世界现在什么样、谁改了什么 | 是（视觉投影 + 语言投影） |
| AI agent | 我能做什么、做过什么、结果如何 | 是（`act` 事件 + 语言投影） |
| 未来的第二人（接手者） | 怎么跑起来、为什么这么设计 | 部分（文档 + 纯文本格式；K-02 仍开） |
