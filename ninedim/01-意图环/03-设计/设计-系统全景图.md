## 一、一句话与一张总图

> **世界不是"存起来的"，是"从一串语义事件里算出来的"。**
> 人、AI、机器三方**都只写事件、都只读投影**，彼此不直连；**一个进程能写、两个进程只能看、一只手只执行**。

```text
                          人                         AI agent                    机器 / 设备
                    （看视觉投影）                （读语言投影）              （写"我做了什么"）
                           ▲                            ▲                            │
                           │                            │                            │
        ┌──────────────────┴────────────────────────────┴────────────────────────────┴─────────┐
        │                       ① 内核 worldd —— **唯一写者**（语义世界的法与账）                  │
        │                                                                                        │
        │   本体（法律·形状）      门禁策略（法律·权限）         静态墙（文件/目录/软链/属主）        │
        │        └──────────┬───────────────┘                              │                     │
        │                   ▼                                              │                     │
        │          ★ 唯一写入口：取号 → 造事件 → 法律校验 → 门禁裁决 → 落笔                          │
        │                   │                                              │                     │
        │                   ▼                                              │                     │
        │   账本（真相：一行一条语义事件，只追加、带摘要链、单写者锁）                                  │
        │                   │  折叠 fold(events)                                                  │
        │                   ▼                                                                     │
        │   读模型（状态：**算出来的，不保存**）                                                      │
        │                   ├────────► 语言投影（给程序读）  ──┐                                     │
        │                   └────────► 视觉投影（给人看）    ──┴─► 同源核对（词表 hash + 状态指纹）     │
        │   通道（总线入口：一个套接字一个身份，权限即身份）                                            │
        └───────────────────▲────────────────────────────────────────────────────────────────────┘
                            │  一行一帧纯文本 JSON（**不含身份**，身份由内核按连接给出）
                            │
        ┌───────────────────┴────────────────────────────────────────────────────────────────────┐
        │                  ② 载体执行器 world-actd / carrier —— **只执行、不裁决**                  │
        │   按执行清单（cap.d）调载体：设备 · 包管理 · 进程 · 载体撤销点 · 等人确认                       │
        │   ⚠️ 它对账本**零写权限**；它写世界的唯一通道是上面那条线                                      │
        │   ⚠️ 它**可以拒绝**（清单没有、连不上内核），**永远不能放行**（门禁说了算）                      │
        └────────────────────────────────────────────────────────────────────────────────────────┘
                            ▲
                            │  只读消费（自持游标 = 已读到第几条）
        ┌───────────────────┴────────────────────────────────────────────────────────────────────┐
        │                  ③ 投影服务 world-projectd —— **零写权限**                              │
        │   语言投影 / 视觉投影（两块出口彼此不交互）；落后了自行全量重算或从检查点续算                    │
        └────────────────────────────────────────────────────────────────────────────────────────┘
```

**三条铁律**（图上三处 ⚠️ 就是它们）：

1. **账本只有一个写者**（内核进程）。其余任何进程都只能**请求**，**没有任何进程能自己写账本**。
2. **法律与真相放在被管者写不到的地方**（不同身份 + 文件/目录权限 + 属主断言；不合格就**拒绝启动**）。
3. **手没有法就不许动**：连不上内核 ⇒ **拒绝执行**，不做本地降级、不排队、不假装成功。

## 二、一个动作怎么穿过去（真实账本，逐字来自现场）

以"agent 请世界启动一个长任务"为例，**顺序不可交换**：

```text
① 意图 ── agent 经通道提交 act 请求
         {"capability":"job.start","verb":"start","request_id":"r-A","params":{…}}
         ↓ 内核：本体校验（形状） → 门禁裁决（允不允许 / 要不要加摩擦）
         ↓ 通过 ⇒ 意图事件落账本（应答里带回它的 id，这是下面因果的锚点）
② 执行 ── 适配器**拿到"通过"之后才**动载体（此刻它是唯一会动东西的地方）
③ 结果 ── 适配器把结果作为**另一条事件**提交，`trace` 指回①的 id
```

**真实账本（三行，就是世界的全部真相）**：

```json
{"seq":1,"kind":"act","id":"e…489-0","actor":"world://agent/1","chain":"fnv1a64:115529c37ab80eb4",
 "body":{"capability":"job.start","verb":"start","request_id":"r-A","params":{"command":"/bin/true","job_id":"j-A"}}}

{"seq":2,"kind":"act","id":"e…142-1","actor":"world://agent/1","chain":"fnv1a64:32a80861c3c62cde",
 "trace":"e…489-0",                                  ← ★ 因果：引发本条的是第 1 条
 "body":{"capability":"job.start","verb":"start","request_id":"r-A",
         "params":{"result":"ok","exit_code":0,"detail":{"job_id":"j-A","status":"running","pid":97223}}}}

{"seq":3,"kind":"notice","id":"e…131-3","actor":"world://agent/1","chain":"fnv1a64:ce107c05c3408743",
 "body":{"type":"gate.awaiting-approval","subject":"world://agent/1",
         "payload":{"capability":"ledger.compact","verb":"install","request_id":"r-B",
                    "reason":"能力不可逆，而该主体不在白名单内……"}}}
```

**第 3 行是被拦下的那一次**——注意两件事：
- 被拒的动作**没有**进 `act`（它没发生）；
- 但它**留了痕**（一条 `notice` 流水）——**拦得住，也记得下**。

**从这三行算出来的状态**：`已折叠 3 条（last_seq=3） act=2 notice=1，指纹 fnv1a64:d55f806678903a99`。
**两块投影同源**：`✅ 语言投影与视觉投影一致（同一读模型 + 同一词表）`。
**孤儿检查**：`✅ 没有『有意图、无结果』的请求`。

## 三、九个模块 + 一个适配器（现在都是什么状态）

| 号 | 模块 | 一句话职责 | 源码 | 状态 |
|---|---|---|---|---|
| `M01` | **本体** | 法律·形状：一条事件长什么样、什么算合法变更；给出**词表身份**（内容寻址） | `ontology.rs` / `ontology.json` | ✅ 已实现 |
| `M02` | **账本** | 事实：只追加的语义事件日志；分配 `seq`；单写者锁；摘要链；崩溃尾迹处理 | `ledger.rs` | ✅ 已实现 |
| `M03` | **读模型** | 状态 = `fold(账本)`；**纯派生物，随时可删掉重算** | `readmodel.rs` | ✅ 已实现 |
| `M04` | **运行时** | 装配与启动；持有**唯一写入口**（取号→造事件→法律→门禁→落笔） | `lib.rs` / `main.rs` | ✅ 已实现 |
| `M05` | **门禁 + 静态墙** | 一件事**现在能不能做**：默认拒绝 + 按不可逆性加摩擦 + 拒绝留痕；法律与真相不得对被管者可写 | `gate.rs` / `guard.rs` | ✅ 已实现 |
| `M06` | **语言投影** | 结构化出口（逐行 JSON + 同源头），给程序读 | `project/language.rs` | ✅ 已实现 |
| `M07` | **视觉投影** | 渲染出口（排版仍可被审计），给人看 | `project/visual.rs` | ✅ 已实现 |
| `M08` | **检查点** | 带基准序号的**缓存**，不是真相；删掉必须无后果 | `checkpoint.rs` | ✅ 已实现（已接 CLI） |
| `M09` | **通道** | 跨进程入口：**一个套接字一个身份，权限即身份** | `channel.rs` | ✅ 已实现（已接 CLI） |
| **`M10`** | **载体适配器** | **载体侧的手**：按执行清单调载体、做载体撤销点、等人确认；**只执行、不裁决** | `carrier/`（7 件） | ✅ 已实现（本轮新增） |

**体量**（现场实测）：Rust **21 个源文件 / 6591 行**（`src`）+ **2435 行**（`tests`）；发布二进制 **865 712 字节**；CLI **22 个子命令**。

**外部依赖：只有一个 `serde_json`。** 账本、本体、策略、协议、清单**全是纯文本 JSON**——**换语言 ≒ 世界不归零**。

## 四、22 个子命令 = 现在真的能做的事

## 五、现在到哪一步了 —— 已经有的 / 还没有的

### ✅ 已经成立（每条都有可执行的判据，且都实测过）

| 能力 | 判据（可机械核对） |
|---|---|
| 语义事件是唯一真相 | 跑完全部只读命令后账本 **`sha256` 不变** |
| 唯一写入口是**编译期事实** | 库里带一条 `compile_fail` 文档测试：外部改 `World.ledger` **必须编译失败** |
| 法律在前、落笔在后 | 被拒事件**不落笔**且账本行数不变 |
| 门禁不可绕过 | 默认拒绝 + 不可逆分级 + 拒绝留痕；`change` 也必须过闸 |
| 状态是算出来的 | 增量折叠 ≡ 全量折叠；**前缀折叠必须给出不同指纹**（反假断言） |
| 两块投影同源 | 换一份词表 ⇒ **必须检出**不一致 |
| 回滚不改历史 | 回滚 = **追加补偿事件**；不提供"撤销" API |
| 坏账本拒启 | 缺号 / 篡改链 / 半行（可恢复）/ 重复身份 —— 各有会红的用例 |
| 只读不写真相 | 只读命令在含半行的账本上跑，**字节逐字节不变** |
| 三进程形态 | 内核唯一可写；适配器连不上内核即**拒绝执行**且**零副作用**；意图先于结果、因果闭合 |

### ⚠️ 明说的边界（**不假装满足**，都写在代码注释与需求里）

| # | 没有的东西 | 代价/现状 |
|---|---|---|
| 1 | **v1 没有审批通道** | 不可逆动作只认白名单主体；被摩擦的主体拿到的是"不要等批准，它不会来" |
| 2 | **门禁的强制力靠文件权限，不靠内核自缚** | 未接 Landlock / seccomp；"不可绕过"= **进程边界 + 权限位**（跨 uid 时成立） |
| 3 | 静态墙**只看 mode 位，不看属主** | 属主由部署方用 `--owner-uid` 显式断言；没人传它就不跑（**不是默认可绕过，但也不是自动**） |
| 4 | 通道**一次一连接**、仅 Unix | 长驻形态已能收 N 个连接，但**尚无并发**；"套接字激活"形态**未实装** |
| 5 | **快照格式、账本保留窗、优雅停机** | 均未定；停机最多留一个残缺末行，下次启动丢弃 |
| 6 | 覆盖率：总行 **76.97% < 80%** | 拖后腿的是**命令入口层 32.91%** 与**通道 56.38%**；分支项**不可判**（量具不产分支数据） |
| 7 | 整本重写**检不出** | 摘要链只能检局部篡改；用例名就叫 `c18_chain_cannot_detect_a_full_rewrite` |
| 8 | 载体侧**长任务的后台等待** | 本次只做"同步执行 + 结果回写"；等待者进程与完工台账未做 |
