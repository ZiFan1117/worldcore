## §1 一句总纲

> **世界里每一样东西，先按时间的问法分开"发生的"与"持存的"；持存的那一半再按依赖的问法问"它靠什么才在"；不属于世界里任何东西、而是关于世界的一句话，另立一支；说的是怎么读、怎么进、怎么验、字节怎么走的，再另立一支。支定归属，目定格。**

一句话的用法：**判定顺序是死的（先时间、再依赖、后声明、末层外）**；四问问完仍归不进去的，按本仓口径就是"本来应该有这一格，而单子里从来没有这一格"（理论书 6.5 方向二），**登记，不发明**。

## §2 判定规则：来了一个东西，按什么问法归哪一支

### 2.1 四问（逐问给"是"与"否"的落点）

| # | 问法 | 问的是什么 | 是 ⇒ | 否 ⇒ |
|---|---|---|---|---|
| ① | **时间问法** | 它**在时间里展开**吗（有起点、有终点、中间有一段） | **支 B 发生** | 问② |
| ② | **依赖问法** | 它**不靠任何别的东西，也照样在**吗 | **A1 自足存在者** | 分支（见 2.2） |
| ③ | **声明问法** | 它**不是世界里的东西，而是关于世界的一句话**，且**先于实例存在**（改了它，所有实例的读法都变） | **支 C 说法** | 问④ |
| ④ | **层外问法** | 它说的是**怎么读／怎么进／怎么验／字节怎么走**，而不是"世界里有什么" | **支 D 层外** | **归不进去**：登记（§7），**不替它发明一支** |

### 2.2 问②的四条分支（依赖问法的细则）

| 它靠什么才在 | 归哪一目 |
|---|---|
| 不靠任何别的东西 | **A1 自足存在者** |
| 靠某一个具体承载者的构造（构造一变它就没了） | **A2 依身之物** |
| 靠外部制度给的一组情形（承载者的构造不因它变） | **A3 外附之职** |
| 靠"至少有一份副本"、可以多份共享 | **A4 可复制之内容** |

### 2.3 三条判定纪律

1. **顺序不许倒**：先问时间，再问依赖，最后问声明。理由——一次发生与一段记录会在"声明／事实"上纠缠，先按时间切开就不会；而 BFO 的第一次切分正是这一刀，且两侧**互斥**（`bfo-core.owl:932` 在 continuant 上逐字写着 `owl:disjointWith` 指向 occurrent）。
2. **一名只许一物**：同一个东西在树里**只有一个目**。今天同一处被两节各挂一个 `home` 的（`_section_map.sections.订阅形状`），按 §6.3 判应然归属。
3. **类型与实例分开问，但不是两支**：先定类目，再定这一条落在**声明面（支 C）**还是**实例面（支 A／B 的实例）**。例：关系**类型**进 C2；"这两端之间确实有这条关系"是**实例**，属支 A（世界里的一条记录）——今天无载体（§6.2 第 2 行）。

## §3 顶层分类树（一页）

```
世界（本体系的最小核心）
│
├─ A 持存者 ─── 跨时刻保持同一身份的东西（continuant）
│   ├─ A1 自足存在者 ......... 不靠他物而存在：在场者／载体／口／设备／宿主
│   ├─ A2 依身之物 ........... 必须长在某个 A1 身上：性质／倾向／能力
│   ├─ A3 外附之职 ........... 外部制度给的、A1 的构造不因它变：角色／资格
│   └─ A4 可复制之内容 ....... 靠"至少有一份副本"而存在：记录／信息内容／词表／规格
│
├─ B 发生 ───── 在时间里展开的东西（occurrent）
│   ├─ B1 过程 ............... 有段时间、有参与者：一次动作／一次执行／一次交付
│   ├─ B2 过程边界 ........... 零长度的那一瞬：起点／终点／事件的时刻
│   ├─ B3 时间区域与持续 ..... 过程可以在其上展开的那一段：区间／时长／时点
│   └─ B4 历史 ............... 若干过程按序拼成的那条线：世界的因果序
│
├─ C 说法 ───── 不是世界里的东西，是关于世界的一句话（declaration）
│   ├─ C1 存在声明 ........... 世界里有哪些类、各有哪些格
│   ├─ C2 连接声明 ........... 哪两类之间允许存在什么连接
│   ├─ C3 能力声明 ........... 这类东西能被怎样对待（含"可读"）
│   ├─ C4 许可条文 ........... 谁能把哪个能力授给谁／从谁收回
│   ├─ C5 入口引用 ........... 这件事由哪一行落地（只有名，没有体）
│   └─ C6 取值与版本 ......... 受控取值／单位／码族 ＋ 这一版的身份
│
└─ D 层外 ───── 说的不是"世界里有什么"（frame）
    ├─ D1 读法定义 ........... 怎么摆、怎么取：投影首行四要素／位点／形状
    ├─ D2 验法 ............... 怎么验：吊在各要素上的判据
    ├─ D3 接入映射 ........... 哪个口＝哪个身份
    └─ D4 旁道·收据·缓存 ..... 字节怎么走、什么不是真相
```

**读数**：4 支／16 目（A 4 目、B 4 目、C 6 目、D 4 目）。
