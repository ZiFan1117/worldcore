# 00-纲领 · 索引

> **本夹收什么**：**纲领性思考**——比"某一环／某一阶段"更高一层、**不属任何一环**的那批判断与口径。
> **本夹不收什么**：① 属某环某阶段的产物（那些照 `ninedim/_索引-工程域结构与命名.md` 的环/阶段落位）；② 过程（过程进 `06-变更/<变更号>/`）；③ 记录（记录进 `records/`）。

## 一、收件口径（判据式，供人快速判"这该不该进"）

| 问 | 是 | 否 |
|---|---|---|
| 它是不是**对全体**成立（跨环、跨阶段、跨原子）？ | ✔ 可进本夹 | ⇒ 落到对应环/阶段的夹 |
| 它是不是**回答"为什么这么干"**（纲领/理念/咬合），而不是"这一步干什么"？ | ✔ 可进本夹 | ⇒ 落 `01-意图环/…` 或 `06-变更/` |
| 它是不是**对外口径**（锚哪条标准、声称什么／不声称什么）？ | ✔ 可进本夹 | ⇒ 落 `01-意图环/03-设计/` |
| 它是不是**修订/复核/评审过程**？ | ⇒ 走 `06-变更/`／`records/`（**不许**进本夹正文） | — |

## 二、命名与深度（本仓规矩）

- 件名 **`<类>-<名>.md`**，本夹 `类` 用 **`纲领`**（例：`纲领-四目标与三层次.md`）；日期件用 `<名>-YYYY-MM-DD.md`。
- **深度封顶三层**：`ninedim/00-纲领/<件>` 就是底，**不许再建子夹**（要分类就用件名）。
- **正文是正文**：修订/订正叙述**不许**写进本夹件里（进 `06-变更/<变更号>/改动对照.md`）。
- 每件都在 **`ninedim/00-纲领/_索引.md`**（本件）登记；件数/行数**不写死**（以现取为准）。

## 三、与"环"的关系（为什么单开一层）

```
ninedim/
├── 00-纲领/        ← 本夹：不属任何一环的纲领性思考（"为什么这么干"）
├── 01-意图环/      ← 定方向（策划/需求/设计/规格/计划/澄清）
├── 02-枢纽A-前置闸/  ← 未批不许动手
├── 03-执行环/      ← 框架内干活（骨架/实现/测试/团队分工/验证证据）
├── 04-枢纽B-后置闸/  ← 未签不算完
├── 05-尾声/        ← 验收/交付（环外收口）
├── 06-变更/ 07-待审/ records/
```
