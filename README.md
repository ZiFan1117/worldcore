# worldcore · 语义世界

> **一个世界，说法只有一份。**

---

## 一、我们看见的

今天的计算机只认「进程、文件、权限」。

它不认「**谁**、**能干什么**、**干了什么**、**长什么样**」。

于是每接一个新东西——一个智能体、一个应用、一台机器——都要重新谈一遍「我们怎么说话」。

**每接一次，谈一次。**

## 二、我们相信的

- **说法，应该是世界里最基础的东西**，而不是每次连接时临时谈出来的。
- **一个世界，说法只有一份。** 谁接进来，都按它说。
- **一件被写下来的事，要能回答七个问题**：谁做的 · 对什么做的 · 从什么变成什么 · 因为什么才发生 · 排在第几位 · 谁允许的 · 什么单位。
- **说法要能被别人自己核一遍。** 我们不要任何人先相信我们。
- **裁决不在模型里，在记录里。** 模型可以提议；正式结论与签字只有人能下。
- **它不「懂」意思，只把「意思的形式」固定下来。** 理解仍在各方。
- **它在所有参与者之下**：谁都可以依赖它，它不依赖任何参与者。

## 三、我们的结构

### 3.1 底下统一，上面三种模式并列

```
┌──────────────────────────────────────────┐
│ 交互与代理层                              │
│  ├─ 人类模式：人 → GUI/快捷键/点击 → 能力接口 │
│  ├─ 委托模式：人 → 语音/文字/按钮 → Agent → 工具/API → 能力接口 │
│  └─ 混合模式：人 ⇄ GUI/共享状态 ⇄ Agent → 工具/API → 能力接口 │
├──────────────────────────────────────────┤
│ 业务/应用能力层：文件、应用、网络、设置等 API/服务 │
├──────────────────────────────────────────┤
│ 系统服务与管理层：进程、内存、权限、应用管理、审计等 │
├──────────────────────────────────────────┤
│ Linux 内核：硬件抽象、驱动、系统调用        │
├──────────────────────────────────────────┤
│ 硬件                                      │
└──────────────────────────────────────────┘
```

### 3.2 三条入口，一个公共门

```
                    人（看 · 点 · 说 · 写 · 按 · 拖）
                                  │
        ╔══════════════════════════════════════════════════════╗
        ║  交互层：GUI —— 三种模式共用的一张脸                  ║
        ║  人类模式=操作台   委托模式=监督台   混合模式=交接台   ║
        ╚══════════════════════════════════════════════════════╝
                │                              │
                │ ① 点/键（确定性）             │ ② 说/写/点「帮我办」（委托）
                │                              ▼
                │                    ┌──────────────────────────────┐
                │                    │ Agent（可选，不是必经）        │
                │                    │ 只做：意图 → 工具 / API       │
                │                    └──────────────┬───────────────┘
                │                                   │ ③ 工具 / API 调用
                ▼                                   ▼
        ╔══════════════════════════════════════════════════════╗
        ║  能力接口（统一入口）                                 ║
        ╚══════════════════════════════════════════════════════╝
                                  │
                                  ▼
        ┌──────────────────────────────────────────────────────┐
        │ 业务/应用能力层 → 系统服务层 → 内核 → 硬件              │
        └──────────────────────────────────────────────────────┘
```

### 3.3 两个中心，Agent 是可插拔侧链

```
          人的意图（点 / 说 / 写 / 按）
                          │
        ╔═════════════════╧══════════════════════════╗
        ║        公共面（三种模式共用）                ║
        ║   GUI  ◄──────────►  共享状态（混合模式）    ║
        ╚════════╤════════════════════════╤══════════╝
                 │                        │
            直接操作                  委托 / 交替
                 │                        │
                 │              ┌─────────▼──────────┐
                 │              │  Agent（可插拔侧链） │ ← 不需要时可拔掉
                 │              └─────────┬──────────┘
                 │                        │
        ╔════════▼════════════════════════▼══════════╗
        ║      能力接口（统一入口）                     ║
        ╚═════════════════════┬═════════════════════╝
                              ▼
            业务能力层 → 系统服务层 → 内核 → 硬件
```

**两个中心**：

- **交互面（GUI）**：对人怎么说——一屏上是哪些语义结构。**可换**（换渲染器、换帧格式，说法不变）。
- **能力接口（本体）**：谁能做什么、允许没有、做过没有。**不可换**（唯一写路径）。

**三种模式**是两条并联的线；**Agent 是并联客户端**，不是第三层。**GUI 是三种模式共用的操作、监督与交接面**——不是人类模式专属。

## 四、我们想要的世界

- 每个进来的人、每个智能体、每个应用、每台机器，说的是同一种话；
- 发生过的每件事，都留下一条能被复查的记录——**被拒绝的也留下**；
- 换掉底层：换机器、换模型、换界面，**说法不变**。

## 五、为什么值得

不是因为它是「又一个系统」。

而是因为今天**每一种连接都要重新谈判**，而这份成本由每个人、每个团队、每次接入承担。
把「说法」这一层单独做出来，连接就不再从零开始。
